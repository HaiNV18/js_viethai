# Landing Page Vinhomes Grand Park

Trang Landing Page đơn giản giới thiệu dự án **Vinhomes Grand Park** tại TP. Thủ Đức. Đây là sản phẩm **demo / học tập**, không phải trang quảng cáo chính thức của chủ đầu tư.

## Công nghệ

- HTML5
- CSS3 (kèm Bootstrap 5 qua CDN)
- JavaScript thuần (không dùng framework, không có backend)

## Cấu trúc thư mục dự kiến

```
vinhomes-landing/
├── index.html      # Mã nguồn chính
├── style.css       # CSS tùy chỉnh
├── script.js       # JavaScript (cuộn mượt, kiểm tra form, hiệu ứng)
└── images/         # (Tùy chọn) ảnh cục bộ nếu không dùng ảnh từ Unsplash
```

## Các phần của trang

1. **Navbar**: logo chữ "VINHOMES GRAND PARK", menu: Trang chủ, Tiện ích, Pháp lý, Liên hệ.
2. **Hero Section**: tiêu đề thu hút, mô tả ngắn, nút CTA "Đăng ký nhận tư vấn", hình ảnh nằm bên phải.
3. **Features Section**: 3 tính năng nổi bật (Lối sống thượng lưu, Tiện ích tối ưu, Pháp lý nhanh gọn), mỗi tính năng một hình ảnh.
4. **Form đăng ký**: họ tên, số điện thoại, kiểm tra hợp lệ bằng JavaScript.
5. **Footer**: bản quyền và thông tin liên hệ mẫu.

## Cách chạy

Mở trực tiếp file `index.html` bằng trình duyệt. Không cần cài đặt hay máy chủ.

## Tài liệu liên quan

| File | Nội dung |
|------|----------|
| `REQUIREMENTS.md` | Yêu cầu chức năng và kỹ thuật |
| `DESIGN.md` | Quy cách giao diện, màu sắc, bố cục |
| `PROMPT.md` | Prompt hoàn chỉnh để dùng với Antigravity |

## Lưu ý

- Thông tin liên hệ và nội dung là **dữ liệu mẫu**.
- Không đưa số liệu cụ thể (giá, diện tích, lợi nhuận) khi chưa có nguồn chính thức.
- Tên và logo Vinhomes là thương hiệu của chủ sở hữu; chỉ dùng cho mục đích demo.
