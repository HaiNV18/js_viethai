# Prompt dùng với Antigravity

Sao chép toàn bộ nội dung trong khối dưới đây và dán vào Antigravity.

```
Hãy tạo một trang Landing Page đơn giản, hiện đại để quảng cáo dự án Vinhomes Grand Park tại TP. Thủ Đức (đây là sản phẩm demo/học tập).

## Ràng buộc kỹ thuật
- Chỉ dùng HTML, CSS và JavaScript thuần; dùng Bootstrap 5 qua CDN. Không dùng ngôn ngữ backend hay framework nào khác.
- Mã nguồn chính lưu trong index.html. CSS tùy chỉnh viết trong style.css, JavaScript trong script.js (cùng thư mục).
- Giao diện responsive, hiển thị tốt trên cả điện thoại và máy tính.
- Nội dung bằng tiếng Việt.

## Giao diện
- Nền trang: #f2f2f2; chữ chính: #2d2d86. Các thẻ (card) dùng nền trắng #ffffff.
- Phong cách sạch sẽ, sang trọng, nhiều khoảng trắng, bo góc nhẹ, bóng đổ tinh tế.

## Cấu trúc trang
1. Navbar: logo dạng chữ "VINHOMES GRAND PARK" bên trái; menu bên phải gồm Trang chủ, Tiện ích, Pháp lý, Liên hệ. Bấm vào mục nào thì cuộn mượt tới section tương ứng. Navbar thu gọn thành nút hamburger trên mobile.
2. Hero Section: bố cục 2 cột, chữ bên trái, hình ảnh bên phải (chuyển thành chữ trên, ảnh dưới trên mobile). Gồm tiêu đề thu hút mạnh mẽ (ví dụ theo hướng "Sống xanh đẳng cấp giữa lòng Thủ Đức"), đoạn mô tả ngắn 2-3 câu và một nút CTA "Đăng ký nhận tư vấn". Hình ảnh thể hiện nhà phố/biệt thự nghỉ dưỡng và trường Vinschool.
3. Features Section: 3 thẻ ngang hàng nhau (xếp dọc trên mobile), mỗi thẻ có một hình ảnh minh họa khác nhau, tiêu đề và mô tả ngắn: (a) Lối sống thượng lưu, (b) Tiện ích tối ưu, (c) Pháp lý nhanh gọn.
4. Form đăng ký: họ tên, số điện thoại, nút gửi. Dùng JavaScript kiểm tra dữ liệu hợp lệ và hiển thị thông báo cảm ơn (không cần gửi dữ liệu đi đâu). Nút CTA ở Hero cuộn xuống form này.
5. Footer: dòng bản quyền, địa chỉ, số điện thoại và email mẫu (dữ liệu giả).

## Hình ảnh
Dùng ảnh từ Unsplash (link trực tiếp, có thuộc tính alt mô tả) hoặc ảnh placeholder nếu không tìm được link phù hợp.

## Lưu ý
- Không bịa số liệu cụ thể (giá, diện tích, lợi nhuận); dùng mô tả chung chung.
- Code có chú thích ngắn, dễ hiểu cho từng phần.
```

## Mẹo sử dụng

- Yêu cầu agent lên kế hoạch ngắn trước khi viết code.
- Sau khi có bản đầu, chỉnh từng điểm nhỏ (màu, khoảng cách, nội dung) thay vì viết lại cả prompt.
